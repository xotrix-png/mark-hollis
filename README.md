# MARK HOLLIS

Premium portfolio for MARK HOLLIS — independent landscape architect focused on private gardens.

Phase 1 delivers the Hero only: editorial typography, asymmetric layout, full-bleed photography, and restrained motion.

## Stack

- React + Vite
- Modern CSS (custom properties, grid)
- Semantic HTML

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Structure

```
public/images/   public/fonts/
src/components/  src/sections/  src/styles/  src/assets/
src/App.jsx      src/main.jsx
```
